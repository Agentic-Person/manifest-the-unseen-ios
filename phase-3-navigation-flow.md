## Database Schema

```sql
-- Table: workbook_progress
┌─────────────┬──────────┬─────────────┬───────────────────┐
│ user_id     │ uuid     │ FK → users  │ NOT NULL          │
│ worksheet_id│ text     │             │ NOT NULL          │
│ phase_number│ integer  │             │ NOT NULL          │
│ data        │ jsonb    │             │ (worksheet data)  │
│ updated_at  │ timestamp│             │ NOT NULL          │
│ created_at  │ timestamp│             │ DEFAULT now()     │
└─────────────┴──────────┴─────────────┴───────────────────┘

-- Primary Key: (user_id, worksheet_id)
-- Ensures one record per user per worksheet

-- Example JSONB data for smart-goals:
{
  "goals": [
    {
      "id": "goal-1705612345678",
      "title": "Run a Marathon",
      "specific": "Complete a full 26.2-mile marathon",
      "measurable": "Finish time under 4 hours",
      "achievable": "6-month training plan with coach",
      "relevant": "Aligns with my health and fitness values",
      "timeBound": "Weekly mileage milestones",
      "deadline": "2026-07-15"
    }
  ]
}
```

## User Journey Example

```
1. User logs in → /workbook
2. User clicks "Phase 3: Goal Setting" card
3. System redirects to /workbook/phase/3/smart-goals (first worksheet)
4. User creates 3 SMART goals with deadlines
5. System auto-saves after 30 seconds
6. User clicks "Next Worksheet" button
7. System navigates to /workbook/phase/3/timeline
8. User adds 5 milestones with dates
9. User marks 2 milestones as completed
10. System auto-saves
11. User clicks "Next Worksheet" button
12. System navigates to /workbook/phase/3/action-plan
13. User adds 10 action steps
14. User reorders steps using arrow buttons
15. User changes status of 3 steps to "In Progress"
16. User completes 2 steps
17. System auto-saves
18. User clicks "Next Worksheet" button
19. System navigates to /workbook/phase/4 (next phase begins)
20. User can return to Phase 3 anytime via /workbook
```

## Key Features by Worksheet

### SMART Goals
- ✅ Multi-goal support (unlimited)
- ✅ 5 SMART criteria fields
- ✅ Date picker for deadlines
- ✅ Edit/View toggle mode
- ✅ Delete confirmation
- ✅ Color-coded framework reference

### Timeline
- ✅ Visual timeline with dots
- ✅ Auto-sort by date
- ✅ Completion toggle
- ✅ Overdue detection
- ✅ Progress dashboard
- ✅ Color-coded status (3 states)

### Action Plan
- ✅ Numbered steps
- ✅ Drag-free reordering (arrows)
- ✅ 3-state status system
- ✅ Optional deadlines
- ✅ Progress bar
- ✅ Line-through completed items
