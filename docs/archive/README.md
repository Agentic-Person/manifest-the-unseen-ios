# Archive

Historical documentation preserved for reference. These documents represent completed work, past decisions, or superseded approaches.

---

## Archive Policy

Documents in this directory are **read-only** and kept for historical reference. They should not be updated unless correcting critical errors.

**Why archive?**
- Preserve historical context for decisions
- Keep main docs focused on current state
- Maintain institutional knowledge

## Contributing to Archive

When archiving documents:

1. Move the file to the appropriate date folder (`YYYY-MM/`)
2. Add an entry to this README
3. Update any cross-references in active documentation
4. Commit with message: `docs: archive [document-name] to archive/YYYY-MM/`
